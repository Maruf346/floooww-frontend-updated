# Dashboard UI Guidelines

- Animate dashboard content when it enters the viewport. Use slow, restrained motion: approximately 0.65–0.9 seconds for card reveals and 1.2–1.4 seconds for graph strokes.
- Prefer opacity plus a small upward translation for cards. Stagger related tiles by about 60–90ms.
- Animate data visualizations progressively where practical: line paths draw, bars grow from zero, and donut/chart content gently scales in. Respect `viewport: { once: true }` to avoid distracting repeated motion while scrolling.
- Apply this visualization-level motion consistently to supporting analytics cards as well: ranked bars, stacked segments, demographic columns, funnels, comparison bars, and budget donuts should animate their data while their shell remains visually stable.
- On Brand project overview desktop layouts, keep the right-rail “What to do next” card sticky with a `24px` top offset while the main project content scrolls. Leave it in normal document flow below the desktop breakpoint.
- The empty Brand Project Applications tab uses a compact Figma-style status rail and filter toolbar above a centered `294px` minimum-height empty-state card. Keep the title at `14px`, description at `13px`, `56px` muted icon tile, 40px actions, and `12px` counts; all filters are functional custom drawers.
- The populated Brand Project Applications tab uses the supplied 1116px composition: a `40px` toolbar, then a three-column grid of `461px` applicant cards with 16px gutters. Each card keeps its fixed Figma vertical rhythm for the 56px applicant header/match ring, platform line, source caption, 56px stat strip, note, 78px fee panel, and two 32px action rows. Stack at smaller widths without shrinking the card typography.
- Brand Project Applications is context-driven without changing its layout: UGC/AI Video swaps Followers and Eng. rate filters for Portfolio and Turnaround, Gift swaps Fee for Asks, channel/stats/fee copy responds to Type/Partnership/Duration, and the footer says `applications close` for one-time or `open until` for long-term. Action order is Message, View profile, then Decline / Shortlist / Invite; use semantic SVG icons and blue/red/neutral button treatments rather than text-glyph replacements.
- Application tab badges, status-rail totals, and the `Showing … of …` footer must derive from the project’s application count; never hard-code a design-reference count.
- Project application action rows match the reference by status: New and Reviewed cards use three equal neutral-outline Decline and Shortlist buttons plus a blue Invite button. Shortlisted cards use a borderless Remove text action beside the blue Invite button. Declined cards use neutral-outline Undo decline beside a blue Shortlist button. Both rows are `32px` tall with `8px` gaps.
- Project application action buttons are text-only when the supplied reference is text-only; do not add Message, profile, or decision icons unless the Figma/MCP output explicitly includes them.
- When a Figma/MCP output supplies an icon for a control, preserve that semantic icon in the implementation; do not substitute a generic icon solely because the label still makes sense.
- Use Lucide or Tabler SVG icons for UI controls such as dropdowns, sort affordances, actions, and navigation. Never use Unicode/text glyphs as icon substitutes in production dashboard UI.
- The Brand Project Applications “View profile” control opens the reusable applicant slide-over: `640px` maximum desktop width, full viewport width on small screens, a dimmed backdrop, a slow right-to-left entrance, and a body-scroll lock. Preserve the Figma’s `24px` desktop gutters, `64px` identity avatar, `72px` match ring, status/verified badges, fee and intro-video blocks, and horizontal profile tabs. All drawer content, including its header and tabs, scrolls together; only the fixed three-action footer remains sticky. Animate the fit bars from zero once the drawer opens.
- The applicant drawer’s Social stats tab follows the supplied `592px` inner width: a `60px` four-platform selector, platform summary and reach/activity metric cards, a `292px` country-map card, `192px` age/city pair, `110px` gender card, and `234px` follower-growth card. Keep the white outlined cards, muted metric surfaces, indigo data palette, and slow one-time bar/column/map reveals.
